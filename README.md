# My Journal v5 — CMS-ready offline edition

Open `index.html` for the blog.
Open `admin.html` for the CMS.

New in v5:
- Dashboard statistics
- Published / Draft status
- Search posts
- Cover image upload + preview
- Edit / delete / publish / unpublish
- JSON export backup
- JSON import restore
- Persistent browser storage
- Dark mode

Important: this is still a static/offline CMS demo. Browser localStorage is not secure authentication and is not shared between devices. For production, connect the UI to a backend/database and real authentication.
